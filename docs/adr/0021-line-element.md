# ADR-0021：自由线条用「节点外壳 + extJson 端点」

日期：2026-11-05
状态：已采纳
相关：ADR-0018（连线路线）、ADR-0020（框选连线）

## 背景

用户要在「结构」区加一个「线条」：一条可调角度的独立线段，能改颜色、粗细、实线/两档虚线，
水平 / 垂直 / 45° 自动对齐，按住 Shift 强制对齐。

关键约束：**连线（edge）不能当线条用**。`edgeSchema` 强制 `sourceNodeId` / `targetNodeId`，
独立线段没有端点节点；硬塞两个隐形节点会把校验、导出、删除、图层全部弄脏。

## 决策

新增节点类型 `line`（与 `text` / `element` / `sticky` 同级：行为像节点、外观特殊）：

- **几何**：两端点存 `extJson.line.a / b`，**相对节点左上角**；节点 `x/y/width/height`
  永远等于「两端点包围盒，夹到 schema 下限 64×40（多出来的空白居中）」。
- **样式**：颜色复用节点 `borderColor`（用户选定，好处是与普通节点混选时交集正好剩颜色，
  可以一起批量改）；粗细与虚线存 `extJson.line.width / dash`，虚线三档直接复用连线的
  `EDGE_DASH_PRESETS`（实线 / `6 4` / `12 8`），一张图里节奏统一。
- **拖端点**：`snapEndpoint()` 把角度按 45° 步进取整，偏离 8° 内自动吸附，按住 Shift 强制吸附；
  吸附保持长度不变。端点一动，`setLineGeometry()` 一次性写回 `x/y/width/height + a/b`。
- **相对坐标的价值**：拖动线条、拖进分组、复制粘贴、撤销重做全部沿用现有节点链路，
  不需要"移动时同步平移端点"这类容易漂的补偿逻辑。
- **渲染**：`ArchNode` 只做分派（`ArchBox` / `ArchLine` 两个组件各自 Hook 稳定），
  线条不画边框、不画文字、不挂 `NodeResizer`，选中时只在线上盖一层淡色加粗 + 两个端点圆点。

## 放弃的方案

- **用连线 + 隐形端点节点**：污染数据模型，删节点会连带删线，导出多两个幽灵节点。
- **新建 `arch_line` 表**：多一套 schema / RLS / 保存函数 / 迁移，收益只是"类型干净"，
  而线条本质就是装饰元素，跟着节点一起保存最省事。
- **把端点存绝对流程坐标**：那样每次移动节点都要同步平移端点，分组拖动、撤销、
  多人合并全是坑。
- **给线条画包围盒选中框**：64×40 的最小盒子里只有一条细线，画框比线本身还抢眼，所以只高亮线本身。

## 已知边界

- 线条不参与连线（没有连接手柄），也不吸到节点边框（v1 明确不做）；
- 端点手柄只在选中且未锁定/未进拖动模式时出现；
- 线条参与对齐工具与图层面板，名称固定为「线条」（可双击改名，属性面板不提供名称输入）。
