# 架构拓扑绘图工具 · 使用说明

> 面向内部使用者的操作手册。技术细节见 `docs/架构拓扑绘图工具-技术规格-v1.0.md`，阶段进度见 `docs/阶段实施计划.md`。

## 1. 打开

线上地址：**https://helisz.github.io/web-architect/**（GitHub Pages，进站先登录，见下面「登录」）。

### 登录

打开后会先看到登录页：填**邮箱 + 密码**，点「登录」。

- 账号**和工具箱共用**：同一个 Supabase 项目里的 Auth 用户是项目级的，所以你在工具箱能登的邮箱密码，这里直接能用，不用另建账号。
- 站点**不提供注册**（公开站点，开放注册等于谁都能改图）。要给别人开权限找管理员：Supabase Dashboard → Authentication → Users → Add user（勾 *Auto Confirm User*）。
- 登录状态会记住，刷新、关掉重开都不用再登；顶栏**最右边**的圆形头像，鼠标移上去（或点一下）就有「退出登录」。
- **登录成功会直接进图库**（#/gallery），不进上次那张图；要接着改，从图库里点卡片进去。
- 换浏览器/换设备要重登一次（会话存在本地）。
- 忘密码：让管理员在 Dashboard 里重置，或者用工具箱那边的「忘记密码」流程 —— 两边是同一套账号。

### 只看得到自己的图

账号是**按人隔离**的：图库只列你自己创建的图，别人的图你打不开（会提示"这张图不存在，或者不是你创建的"）。
这条边界在数据库里（Supabase RLS 按 `creator_id = auth.uid()` 判），不是前端藏起来的 —— 换个地址、直接调接口也读不到别人的。

由此带来两个使用上的变化：

- **没有协作**：两个人不能同时看/改同一张图。要把图给别人，走「导出 → JSON」，对方「导入」后得到**自己名下的一份副本**，之后各改各的。
- **归属跟账号走**：换账号登录看到的是另一批图；同一个账号换设备/换浏览器看到的还是你那批。

```bash
npm install          # 首次
npm run dev          # 打开 http://127.0.0.1:5273
```

打开的**图库**地址是 `/#/gallery`（`#/` 这种老地址会自动改写成它）。所有架构图按更新时间排，**点卡片本身**就进图；画布顶栏最左边常驻一个「‹」，随时回图库。每张图都有自己的地址，形如：

```
http://127.0.0.1:5273/#/d/ca348941-d53a-479b-b0d1-b5920b277d47
```

所以刷新、存书签、把链接发给同事，打开的都是同一张图；浏览器**后退键**就从图回到图库。图库右上角「＋ 新建架构图」建一张空图并直接进去。

图库卡片：一张卡片固定 320px 宽（宽屏一行 4~5 张），点卡片任意空白处即进图；右下角三个图标分别是**改名 / 复制 / 删除**（鼠标停一下有说明），标签行末尾的「改标签」还能顺手打标签。卡片标题太长会省略，鼠标停上去看全名。

进了画布后，顶栏从左到右：「‹」返回图库、图名（可直接改）＋保存状态＋版本号、数据库状态（绿点 + 库图标，鼠标移上去看延迟/报错）、撤销 / 重做、版本 / 连线设置 / 组件库 / 网格、搜索、导入、导出，最右边是账号。**除导入导出外，功能按钮都只显示图标**，鼠标停一下就是说明文字。

## 2. 画一张图

| 想做的事 | 怎么做 |
| --- | --- |
| 加节点 | 从左侧「组件」面板把组件拖到画布（面板两列，只显示图标 + 名称）；面板可以整栏收起，用顶栏的「组件库」按钮开关 |
| 加分组 | 从左侧「结构 → 分组」拖到画布（默认 360×240）；也可以直接拖「服务器 / 集群 / nginx」三个预设，建出来就带图标和副文本 |
| 加标题 / 文本 / 便利贴 / 注释 | 从左侧「文本」分类拖到画布。这四种都是**真节点**：能连线、能放进分组、能多选对齐 |
| 调气泡尖角 | 选中「注释」后，尖角末端有个蓝色小圆点，拖着它转方向（自由角度，360° 任意；左侧的尖角就从左边射出） |
| 连线 | 鼠标移到节点上，四边各浮现一个小圆点，从任意一个圆点拖出，**松手落在目标节点任意位置**即可连上（自动选最近的一边）；拖动过程中能看到一条蓝色虚线 + 箭头预览，松手前一直跟着指针 |
| 改大小 | 选中节点/分组后拖四周手柄（节点最小 64×40，分组最小 120×80，尺寸按 10px 取整）；节点属性里不再放宽高数字，分组的宽高还在 |
| 改名字 | **双击**节点或分组标题，Enter 提交、Esc 取消 |
| 改颜色/图标/线型 | 选中后在右侧属性面板改；颜色是一个「颜色」按钮，气泡里是固定色块（见下）；「图标」下方是一行可横向滑动的常用 19 个，或点「搜索图标库…」搜全库 |
| 删除 | 选中节点或连线按 `Delete` **直接删**；删分组、或一次选中多个元素时才弹确认框 |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），也可点顶栏按钮 |
| 平移 | 按住**空格**再拖动，或点右上角**拖动模式**（手形图标）后直接拖空白处；普通滚轮上下平移 |
| 缩放 | 左下角 `+` / `−` 按钮，或 `Ctrl`（Mac 上 `Cmd`）+ 滚轮，都是**按 20% 一档**走：80% → 100% → 120% …；点「适配视图」自动缩放到刚好装下全图（可能是 87% 这种数），之后再按 `+` / `−` 会自动对齐到相邻档位（87% → 100% 或 80%）；右下角有 MiniMap（点/拖它也能导航） |
| 多选 | 空白处拖出选框，或按住 `Ctrl`/`Shift` 点选；多选状态下 `Shift`/`Ctrl` 再点已选中的元素 = **取消它**；选中的元素可一起拖动、一起删。**框选只选节点和分组**，连线要单独点（`Shift+点` 可多选几条一起删） |
| 改连线路线 | 选中一条连线后，线上会出现三个小手柄：**拖两端的圆点**换进出口（从节点的哪条边连出/连进）；**拖线上的小＋**加一个折点（可以加很多个，最多 12 个，按 10px 吸附），折点可以继续拖；**双击折点**删掉它。三种线型都支持折点，松手才算一步撤销 |
| 多选批量改 | 选中多个元素后，右侧只出现「所有元素都有」的属性（名称、副文本、背景色、边框色、文字颜色、图标、水平对齐、垂直对齐；连线还有线宽、线型、箭头、虚线），改一次全部生效；值不一致显示「多个值」。节点和连线混选时只剩名称 |
| 对齐文字 | 属性面板「文字」区的两组按钮：水平 ⇤ ↔ ⇥、垂直 ⤒ ⬍ ⤓，节点和文本节点都吃这套；多选时也能一起改 |
| 锁定编辑 | 画布右上角最右边的「锁定编辑」按钮，锁上以后只能看 / 选中 / 平移 / 缩放 / 搜索，拖动、改尺寸、改属性、连线、删除、拖入全部关掉；再点一下解锁（见下） |
| 网格 | 顶栏「网格」按钮开关，画布是 10px 间距的网点；拖动与改尺寸也按 10px 吸附 |

> 一次拖拽（哪怕中间派发了上百次移动）只算**一步**撤销，不会撤销到手酸。

画布左下角（贴着底边、`+`/`−`/适配视图 三个按钮右边）有一行小灰字：缩放比例（点一下真的回到 100%）、鼠标坐标、节点/连线/分组数量、schema 版本。
原来底部那条状态栏已经撤掉，内容都收进这一行。

「提醒」和「报错」这类说完就完的信息，现在是画布底部居中的 **toast**，几秒后自己消失，也可以点右边的 × 提前关掉（导入修复了几处、恢复了本地草稿、应用到全部连线、新建/复制成功、快照/回滚、图库里载入失败等都走这个）。
**需要你拍板的**仍然留在顶部横幅里：版本冲突（「放弃本地改动」/「用我的版本覆盖」）、另一个标签页正在编辑、保存失败（「重新载入」）、保存函数还没建（要人跑 SQL）。

连线默认样式在顶栏「连线设置」（滑杆图标）里：线型（正交折线 / 贝塞尔 / 直线）与线宽，只作用于**新建**的线；
想让当前设置套用到整张图，点同一面板里的「应用到全部 N 条连线」。新线默认 **灰 #6B7280 / 2px / 单向箭头**，
箭头指向你拖线的方向（从 A 拖到 B，箭头就指 B），方向可在属性面板改成 无 / 单向 / 反向 / 双向。
线头两侧都**贴着节点边框**，箭头大小固定 10px（不随线宽/缩放放大），改了线宽也不会变成大三角。
正交折线用的是 React Flow 官方 `getSmoothStepPath`（出线 20px、圆角 5px），走线只有水平/竖直段，
不会为了躲节点绕圈或走斜线（自研绕行逻辑已下线，见 ADR-0012）。

**连线可以改路线**（选中以后才出手柄，见上表「改连线路线」）：
拖两端圆点换进出口、拖线上小＋加折点、双击折点删掉。折点存在连线自己的
`extJson.waypoints` 里（随图保存，**不需要跑任何 SQL**），老图没有折点时还是自动走线、逐像素不变。
带折点的线：直线走折线（拐角 5px 圆角）、正交线走横竖段、曲线用 Catmull-Rom 穿过每个折点，
标注钉在路径的中点；有标注时"小＋"会自动挪到路径 1/4 处，不压住文字。

**多选连线**可以对一批线一次改完：线宽、线型（正交/贝塞尔/直线）、箭头（无/单向/反向/双向）、虚线；
删多条线时确认框会报出是哪几条（`A → B（443/TLS）`），最多列 4 条再"等"。

**虚线**只有三档：实线（默认）/ 短虚线 / 长虚线，属性面板里三个按钮**直接画出线型样子**
（不再是「实线」两个字），鼠标停一下有文字提示。老图里如果有别的虚线值，
面板会提示「当前是自定义虚线」，点任一档就覆盖掉了。

**分组也能连线**：鼠标移到分组上，四边同样浮现小圆点，从圆点拖到另一个分组或节点即可
（分组 → 分组、节点 → 分组、分组 → 节点都行）；反过来更省事：**从节点的圆点拖出来，松手落在分组身上**
就接上了（落点自动接最近的一边）。分组边框被别的节点压住时手柄点不到，把分组挪开一点、或走"从节点拖进分组"这条路。
连线挂在分组身上，删除/解组这个分组时线会一起删。
⚠️ 这一项需要先在 Supabase 里跑一次 `supabase/patch-edge-group-endpoints.sql`（把 `arch_edge` 端点上的
两个外键去掉），否则保存这种连线会报外键错误；跑一次即可，旧图不受影响。

### 颜色（固定色板）

选中节点/分组/连线后点属性面板的「颜色」，气泡里只有固定色块，没有色轮、也不接受自定义色值。
色块是圆形，当前生效的那一格带蓝色圆环；一共三组：

- **节点背景色**（3 行 × 6 格）
  - 第 1 行：透明（清除背景）、黑 `#000000`、深灰 `#55575C`、浅灰 `#D2D3D6`、极浅灰 `#F2F3F5`、白 `#FFFFFF`
  - 第 2 行：紫 `#924BED`、蓝 `#2563EB`、绿 `#22C55E`、黄 `#FFE033`、橙 `#FF8A29`、红 `#F44336`
  - 第 3 行（浅马卡龙）：浅紫 `#E9DDFF`、浅蓝 `#DBE8FF`、浅绿 `#D7F5D9`、浅黄 `#FFFACD`、
    浅橙 `#FFE9D6`、浅粉 `#FFDDDD`
- **节点边框色**（2 行 × 6 格）：第 1 行同背景色的中性行（第一格是「清除边框」），第 2 行同饱和色行
- **文字颜色**（1 行 9 格，色块里带字母 A）：黑 `#000000`、浅灰 `#868686`、更浅灰 `#B0B1B5`、
  紫 `#924BED`、蓝 `#2563EB`、绿 `#22C55E`、黄 `#FFD000`、橙 `#FF8A29`、红 `#F44336`

「透明」格是真的把颜色清掉：数据里存全透明 `#00000000`（Schema 只收 `#RRGGBB` / `#RRGGBBAA`，
不能写 CSS 的 `transparent`；旧数据里若出现 `transparent` / `none`，读入时自动归一成 `#00000000`）。
连线单独一组「线条颜色」，列中性 + 饱和 9 色。

老数据里不在色板内的颜色不会被改写，只是高亮"最接近的一格"。

## 3. 分组

- **拖节点进分组**：把节点拖到分组框内松手即自动归入；拖出去会自动脱离。
- **整体移动**：拖分组标题栏或空白处，组内节点跟着一起动，不会错位。
- **副文本**：分组属性里可以写小字（例如 `10.0.0.0/24`），显示在标题下面；不写只占一行。
  副文本**可以回车换行**（输入框是两行的），但画布标题栏里**只显示一行**，超出用省略号截断（数据不丢，属性面板里能看到全文）。
- **图标**：分组属性里可以选图标（19 个常用 + 「搜索图标库…」），标题栏左侧显示；图标与**第一行标题**顶部对齐。
- **预设分组**：左侧「结构」里除通用「分组」外，还有 **服务器 / 集群 / nginx** 三个预设 —— 拖进去就是带图标、带副文本的普通分组，之后照样能改名、换图标、嵌套。
- **嵌套**：分组可以放进分组，最多 3 层（再往里放会被拒绝）。
- **折叠**：在**分组属性面板**里勾「折叠」（或右键菜单「折叠 / 展开」），只剩标题条（不带副文本 24px、带副文本 38px）；数据不丢，展开即恢复。标题栏上不再有折叠按钮，避免误点。
- **删除分组**：选中分组按 Delete，先弹确认框；只删框，里面的节点会提升到上一层，不会跟着消失。标题栏上不再有删除按钮。

## 3b. 排版（字号 / 字体 / 对齐）

- **字体**：全站统一 `Inter, "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", system-ui, -apple-system, sans-serif`；
  只有**副文本**（节点副标题、分组副标题）用等宽字体，这样 IP、端口、主机名对齐好看。
- **字号**：节点名称 **12px / 500**，副文本 **10px**；标题 / 文本节点的大标题仍是 **28px 加粗**。
  字号只在属性面板里用数字框改（8–72），**没有**常用字号快选按钮。
- **副文本换行**：节点副文本画布上固定占两行、超出截断；分组副文本只占一行（省略号截断），间距 3px。
- **对齐**：属性面板「文字」里有水平（左 / 中 / 右）和垂直（顶 / 中 / 底）两组按钮，
  对整个节点的文字块生效，文本节点也一样；多选时可以一次改全部。

## 3c. 拖动模式（画布平移）

画布**右上角**有三个图标按钮，从左到右：**图层**（▤）、**拖动模式**（手形）、**锁定编辑**（锁）。都只有图标，鼠标停一下有说明。

- **拖动模式**：点开后，在**空白处拖动 = 平移画布**，节点和分组**拖不动**（避免手滑把图拖乱）；再点一下回到编辑模式。
- 它等于「一直按住空格」：临时平移仍然随时按空格拖，两种方式可叠加。
- 拖动模式只影响当前会话、不写进图；**锁定编辑**才是随图保存的状态。

## 3d. 锁定编辑

画布**右上角**最右边的图标是「锁定编辑」（锁）。点一下变成「已锁定」（图标变蓝），此时：

- **还能做**：选中、平移（空格 + 拖动 / 拖动模式）、缩放、搜索、折叠分组、看属性；
- **不能做**：拖动节点/分组、改尺寸、改属性、连线、删除、从左侧面板拖新元素进来、双击改名、双击改连线标注、右键菜单（锁定时不弹）。

锁定状态**跟着图走**：存在图的元数据里（`arch_diagram.ext_json`），换电脑、换浏览器打开同一张图仍然是锁定的。
⚠️ 这一项需要先在 Supabase 里跑一次 `supabase/patch-diagram-ext.sql`；不跑也能锁，但只对当前浏览器会话有效。

## 3e. 图层面板（层级 + 遮挡）

画布右上角最左边的**图层**按钮打开，面板贴在它下面：

- **层级关系**：按分组嵌套画成树 —— 分组 > 子分组 > 节点，缩进表示层级，点行首的 `▾`/`▸` 展开收起；分组名后面那个数字是它内部的元素个数。
- **改归属**：把一行**拖到某个分组行**上 = 放进这个分组；拖到列表底部的「拖到这里 → 移出分组（顶层）」= 移出分组。成环、超过 3 层的会被拒绝并提示。
- **遮挡顺序**：每行的 `↑` / `↓` 仍然是置顶 / 置底；拖拽只用于改归属，不会再顺手改层级。
- **锁定 / 选中**：行尾的 🔒 点一下锁定或解锁；点名字等于在画布上选中它。

## 4. 保存

- **自动保存按"改动的性质"来排队**（ADR-0008）：
  - 增删节点 / 连线 / 分组 → 停手 **1 秒**就存；
  - 改颜色、文字、位置 → 停手 **3 秒**后存；
  - 一直在改没停手 → 最多攒 **30 秒**也会强制存一次；
  - 两次写库之间至少隔 **10 秒**，连续的小操作会合并成一次。
- **Ctrl/Cmd + S** 立刻保存一次，不等节流。
- **平移和缩放不写库**（只记在浏览器本地），所以看图和画图都不会白白产生版本。
- **增量保存**：只把"这次改动的行"发给数据库（拖一个节点 = 一行），大图明显更快。
  需要先在 Supabase 执行一次 `supabase/patch-diagram.sql`；没执行也能用 —— 前端发现
  `arch_patch_diagram` 不存在会自动回退到整图保存，只是慢一些。
- 顶栏状态：图名右边一行小字 `已保存` / `保存中…` / `未保存`（绿 / 琥珀 / 灰，没有底色），紧挨着版本号 `v314`；失败会在下方弹红条并给出原因。
- 刷新/重开浏览器，内容从数据库恢复。**崩溃 / 误关页面**也不会丢太多：本地每 1.5 秒存一份草稿，重开同一张图会自动恢复并提示。
- **回图库 / 换图前会先存一次**：有没落库的改动就先刷出去再跳，不靠草稿兜底（冲突中、保存不可用、跟随者这三种情况除外，跳之前也不拦你）。
- **另一个标签页正在编辑同一张图**：后打开的那页会提示"另一个标签页正在编辑"，暂时不自动保存；在本页一动手就会自动接手（另一页随之退位），避免两边抢版本。
- **版本冲突**（另一台机器改过同一张图）：如果只是版本号被推高、内容没打架，会自动对齐重试一次；真冲突才弹黄条给两个选择 ——「放弃本地改动，重新载入」或「用我的版本覆盖」。
- **保存不可用**：说明库里还没有 `arch_save_diagram` 函数，把 `supabase/schema.sql` 全文重新跑一遍再刷新。此时画布仍可编辑，但刷新会丢。
- **关窗口提醒**：有未保存的改动、且距上次成功保存超过 3 秒时，关闭/刷新页面浏览器会弹原生确认框（文案由浏览器决定，改不了）。刚存过或只是跟随者页面不弹。

## 5. 导出与导入

**导出 JSON**：顶栏「导出 ▾ → 导出 JSON」，得到 `图名.json`，含分组、节点、连线与视口，不含数据库版本号，可直接给别的实例导入。

**导出 PNG**：顶栏「导出 ▾ → 导出 PNG（1× / 2× / 3×）」，按**全部内容**的包围盒裁剪、四周留 40px 白边。导出前会自动取消选中，选中框、缩放手柄、画布网格都不会出现在图里。

**导出透明底 PNG**：顶栏「导出 ▾ → 导出 PNG（2×，透明底）」，和上面同一套排版，只是背景透明（文件名带 -transparent）。适合贴到 PPT / 深色文档里。

**复制图片**：顶栏「导出 ▾ → 复制图片（2× PNG，白底）」，直接进系统剪贴板，接着就能粘到微信 / 飞书 / Word / PPT 里。
固定 2× 白底，不用选参数；如果浏览器不给用剪贴板（非 https、权限被拒、老浏览器），会自动改成下载
`图名@2x.png` 并提示一句，不会静默失败。

**导出 SVG**：矢量版，和 PNG 同一套渲染，浏览器 / Figma / Illustrator 都能打开（节点是 HTML，SVG 里用 `foreignObject` 承载）。

**导出 PDF**：A4 / A3 横向，一页放下整张图（大图等比缩到页面内，小图 1:1 居中不放大）。
> 说明：画布节点是 HTML，SVG→PDF 的转换工具都不渲染 `foreignObject`，所以 PDF 是「2× 位图嵌入」，不是矢量；打印清晰度有保证。

**导出 CSV**：节点清单 / 连线清单两张表，带 BOM，Excel 直接双击打开不乱码。节点表含**绝对坐标**、所属分组、`extJson.ip`，方便丢进运维台账筛选。

**版本历史**：顶栏「版本」（时钟图标）→ 右侧弹出**版本栏**，列出所有快照（缩略图 + 版本号 + 时间 + 节点/连线/分组数量），可回滚到任意一版。回滚不是"倒带"：它把旧内容当成一次新提交，版本号继续 +1，历史不丢。版本栏和属性面板共用右侧一列 —— 点画布上的元素会自动切成属性面板，再点一次「版本」回来。

**手动快照**：版本栏顶部有个输入框，给当前版本起个名字（例如「上线前」）点「存为快照」。同一版本已有快照时会改成改名，不会报错 —— 想给关键节点留个标记，用它。

**图库**：顶栏最左边的「‹」→ 回图库（所有架构图的卡片列表）。上方可按名称搜索、按标签筛、切换「按更新时间 / 按名称 / 按版本号」排序，每页 12 张。卡片上可打开 / 改名 / **改标签**（逗号分隔，最多 12 个）/ 复制 / 删除。「复制」会把整张图换一套新 id 存成副本，不会覆盖原图。

**导入 JSON**：顶栏「导入」，选文件即可。三条规则：

1. 导入的是**一张新图**，原有图不受影响；
2. 所有 id 重新生成，不会和已有数据打架；
3. 不合法的地方会被自动修复并给出提示，例如未知节点类型 `mysql` 会降级成 `custom` 并显示「其中 1 处不合法已自动修复」。端点不存在的连线会被丢弃。

外部手写的 JSON 也可以导入，最小只需 `{ "name": "...", "nodes": [{ "nodeType": "server", "x": 0, "y": 0 }] }`，其余字段自动补默认值。

## 6. 图标

- 每个节点自动带一个图标，来自 Iconify 官方图标库（通用 / 品牌 / K8s 三套，共 7400+ 个）。
- 换图标：选中节点 → 右侧「图标」→ 点上面的常用图标，或点「搜索图标库…」输入关键词（如 database、nginx、pod）后点选。
- 图标库分段加载：常用 19 个随包内联（含 nginx 的「N」方块标 `arch:nginx`）；打开选择器时加载通用库（约 350 kB gzip），品牌 logo 库在后台继续下载，不挡操作。
- schema 里只存 `iconKey` 字符串，不存图片；导出的 JSON 不会变大。

## 7. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 白屏或提示「保存失败」 | 多半是 `arch_save_diagram` 不存在或 anon 权限被关。跑 `npm run check:db` 看具体哪项不通 |
| 图打不开，提示 schema 不合法 | 库里有超出枚举的 `node_type`。当前版本会自动降级为 `custom` 并提示，不会整张图打不开 |
| 两个标签页同时打开同一张图 | 后打开的一页会提示「另一个标签页正在编辑」，暂不自动保存；在该页一动手就自动接手 |
| 改了没看到「已保存」 | 自动保存要等你停手 1–3 秒（一直在改最长等 30 秒）；想立刻落库按 `Ctrl/Cmd+S` |
| 分组副文本存不下来 / 打开图报列不存在 | 库里还没有 `arch_group.sub_label` 这一列：重跑一次 `supabase/patch-diagram.sql`（顶部有 `add column if not exists`） |
| 注释的尖角拖不动 | 尖角手柄只在**单选**该注释、且没锁定时出现；先点一下注释，气泡边缘会出现蓝色小圆点 |
| 多选后右侧没有颜色 / 文字 | 那批元素没有共同字段（例如节点 + 连线只剩名称）。同类型多选才有背景色 / 边框色 / 图标；多条连线一起选才有线宽 / 线型 / 箭头 / 虚线 |
| 框选选不到连线 | 故意的：框选只选节点和分组，免得框节点时把穿过的线一起选走、一次删掉一堆。连线用单击，或 `Shift+点` 多选 |
| 看不到连线的拖动小手柄 | 手柄只在**选中一条线**且没锁定时出现；「锁定编辑」或「拖动模式」下都不显示。连线有标注时"小＋"在路径 1/4 处，别去找线正中间 |
| 导出的 PNG 边缘有空白 | 四周各留 40px 是有意为之，方便贴进文档时不被文字压住 |
| 换了 Supabase 项目 | 改 `.env.local` 的 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`，并在新项目里跑一遍 `supabase/schema.sql` |
| 打开链接提示「这张图不存在或已被删除」 | `#/d/<id>` 里的 id 在库里没有了（被删或地址抄错）。提示完会自动回图库，重新点一张就行 |
| 右下角 MiniMap 一片空白 | 老版本的问题，已修（节点尺寸要同时给 `width/height` 才画得出来）。还空就强制刷新一次 |
| 拖不出线 / 线头离节点有一截 | 老版本的问题，已修：手柄缩回 8px（命中区仍有 24px），线头改成直接落节点边框，箭头 10px 固定大小。还不对就强制刷新一次 |
| 老图上的线没有箭头 | 箭头是存在每张图里的数据。这条默认值只影响**新建**的线；老图在属性面板把「箭头」改成「单向」即可 |
| 老图上的 nginx 还是旧 logo | 前端已做映射，正常不会出现；若真看到，强制刷新一次。想彻底清库跑 `supabase/patch-nginx-icon.sql` | 触控板一次滑动会连发很多滚轮事件，已做 160ms 节流；如果还跳，说明是多次独立滑动，慢一点按 |
| 提醒一闪就没了 / 想看刚才那句 | toast 4–7 秒自动消失；要留痕的（冲突、保存失败）本来就在顶部横幅里，不会自动消失 |

## 9. 对齐、层级与右键菜单

- **对齐与分布**：选中 2 个以上元素时，画布顶部出现工具条 —— 左/水平居中/右、上/垂直居中/下共 6 种对齐，
  以及水平、垂直 2 种等距分布（≥3 个才能用）。对齐按整体外框算，精度 1px。
- **图层**：顶栏「图层」打开面板，列表按上下层级排列；拖动某一行即可改层级，行尾 ↑/↓ 直接置顶置底。
  分组永远在节点下面，`sort` 会被自动归一化成 0..N-1。
- **搜索**：`Ctrl+F`，按名称、副文本、IP 模糊匹配，回车定位。
- **右键菜单**：
  - 空白：添加节点（按分类）▸、添加分组、粘贴、全选、适配视图、导出、画布设置
  - 节点：编辑名称、复制、删除、锁定/解锁、置顶/置底、加入分组▸、设为起点连线▸、样式▸
  - 连线：编辑标注、改线型▸、改颜色▸、反转方向、删除
  - 分组：重命名、折叠/展开、解组（保留内容）、删除、着色▸、置顶/置底
